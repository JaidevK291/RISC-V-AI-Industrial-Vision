# RISC-V Based AI Industrial Vision Inspection System

## Overview

This project aims to develop a low-cost industrial quality inspection system using a RISC-V processor, FPGA hardware acceleration, computer vision, and artificial intelligence.

The system captures images from a camera, preprocesses them on an FPGA, performs AI-based defect detection, and displays the results through a Python dashboard.

## Objectives

- Design a RISC-V based embedded system
- Implement image processing using FPGA (Verilog)
- Detect manufacturing defects using AI
- Develop a custom PCB using KiCad
- Demonstrate hardware-software co-design

## Technology Stack

### Hardware
- FPGA Development Board
- OV7670/OV2640 Camera
- Custom PCB
- UART, SPI, I²C

### VLSI
- Verilog/SystemVerilog
- RISC-V Core
- FSM Design

### Software
- Python
- OpenCV
- TensorFlow/PyTorch
- VS Code
